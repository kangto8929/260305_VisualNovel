# ═══════════════════════════════════════════════════════════
# {char:캐릭터명} 사용법
#
# 나레이션/대사 텍스트 안에서 캐릭터 이름을 쓸 때 사용
# *reveal 이전 → ??? 로 출력
# *reveal 이후 → 실명(이상) 으로 출력
#
# 예시)
#   Narration||{char:이상}이 웃었다.||...
#   → *reveal 이상 전:  ???이 웃었다.
#   → *reveal 이상 후:  이상이 웃었다.
#
# *reveal 은 대사창 이름칸 + 나레이션 텍스트 양쪽 다 동시에 적용됨
# 대사창 이름칸은 DialogueManager가 자동으로 처리하므로
# 텍스트 안에 이름이 직접 들어갈 때만 {char:이름} 을 쓰면 됨
# ═══════════════════════════════════════════════════════════

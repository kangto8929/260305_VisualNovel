# ─── 노드 ID 규칙 ───────────────────────────────────
# ::S010        챕터 공통 / 시작 씬
# ::S110        1번 선택지 루트 (A루트 - 이상과 이야기하기)
# ::S210        2번 선택지 루트 (B루트 - B와 이야기하기)
# ::S310        3번 선택지 루트 (지나가기 루트)
# ::S111        S110 안에서 1번 선택지 (요즘 바빴어)
# ::S112        S110 안에서 2번 선택지 (그냥 별거 없었어)
# ::S113        S110 안에서 3번 선택지 (너는 어때?)
# ::S111A       S111 안에서 A선택지 (사실 너 때문에 바빴어)
# ::S111B       S111 안에서 B선택지 (고마워 근데 괜찮아)
# ::S111C       S111 안에서 C선택지 (그냥 웃으며 넘겼다)
#
# ─── 이름 태그 규칙 ─────────────────────────────────
# {name}        성+이름 전체 출력          ex) 서준혁
# {fname}       이름만 출력 (성 제외)      ex) 준혁
#
# ─── 조사 태그 규칙 ─────────────────────────────────
# {name:아}     받침O → 아  / 받침X → 야  ex) 서준혁아  / 서민지야
# {name:이/가}  받침O → 이  / 받침X → 가  ex) 서준혁이  / 서민지가
# {name:이가}   받침O → 이가 / 받침X → 가 ex) 서준혁이가 / 서민지가
# {name:은}     받침O → 은  / 받침X → 는  ex) 서준혁은  / 서민지는
# {name:을}     받침O → 을  / 받침X → 를  ex) 서준혁을  / 서민지를
# {name:과}     받침O → 과  / 받침X → 와  ex) 서준혁과  / 서민지와
# {name:으로}   받침O → 으로 / 받침X → 로 ex) 서준혁으로 / 서민지로
# {name:이랑}   받침O → 이랑 / 받침X → 랑 ex) 서준혁이랑 / 서민지랑
# {name:이 형}  받침O → 이 형 / 받침X → 형 ex) 서준혁이 형 / 서민지 형
# {name:이 누나} 받침O → 이 누나 / 받침X → 누나
# {name:이 언니} 받침O → 이 언니 / 받침X → 언니
# {name:이 오빠} 받침O → 이 오빠 / 받침X → 오빠
# ※ {fname:...} 도 위와 동일하게 사용 가능 (이름만 적용)
#
# ─── 대사 형식 ──────────────────────────────────────
# DialogType|Speaker|Text|Expression|Background|ShowMainCharacter|MainExpression
# DialogType        : Narration / Main / Sub
# Speaker           : 나레이션은 비워둠
# Expression        : 말하는 캐릭터의 표정 이름
# Background        : 배경 이미지 이름
# ShowMainCharacter : true(메인 캐릭터 표시) / false(숨김)
# MainExpression    : Sub/Narration일 때 메인 캐릭터 표정 변경
#                     비워두면 이전 표정 유지
#
# ─── 메인 캐릭터 색상 규칙 ──────────────────────────
# Main 타입   → 메인 캐릭터 #FFFFFF (밝게, 자동 적용)
# Narration   → 메인 캐릭터 #B0B0B0 (어둡게, 자동 적용)
# Sub 타입    → 메인 캐릭터 #B0B0B0 (어둡게, 자동 적용)
# ※ txt에 별도 지정 없이 DialogType만으로 자동 처리됨
#
# ─── 선택지 형식 ────────────────────────────────────
# 선택지텍스트,이동할노드ID,Important(true/false),호감도캐릭터,호감도수치
# Important true  → 중요 선택지 버튼 프리팹 사용
# Important false → 일반 선택지 버튼 프리팹 사용
#
# ─── 색상 태그 ──────────────────────────────────────
# <color=#FF6B6B>텍스트</color>   붉은 계열
# <color=#6B9FFF>텍스트</color>   파란 계열
# <color=#A8D8A8>텍스트</color>   초록 계열
# <color=grey>텍스트</color>      회색 (회상, 독백)
# ※ TMP Rich Text 기반, 헥스 코드 자유롭게 사용 가능
